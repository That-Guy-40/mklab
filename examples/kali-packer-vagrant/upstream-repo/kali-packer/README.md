## Kali-Packer

This used to be the home of Kali-Vagrant's build-scripts.

Since [Kali 2025.2](https://www.kali.org/blog/kali-linux-2025-2-release/), the Kali team has stopped using [Packer](https://developer.hashicorp.com/packer) to generate Vagrant VMs and now uses [DebOS](https://github.com/go-debos/debos).
This is the same method used to generate [our other/stock VMs](https://gitlab.com/kalilinux/build-scripts/kali-vm).

**As this repository is no longer responsible for the [Kali Vagrant images](https://portal.cloud.hashicorp.com/vagrant/discover/kalilinux/rolling), it has been renamed to Kali-Packer**.

_This repository is no longer in production, so it may not be up-to-date and accurate._
